# Stability benchmark: pydada2 vs R dada2

Generated by `benchmarks/dataset/report.py` from runs of `run.py`.
Both tools run the [DADA2 tutorial](https://benjjneb.github.io/dada2/tutorial.html)
pipeline (`pipeline.R` / `pipeline.py`) with identical parameters, each run in a fresh
process.

* Data: Stability (Kozich et al. 2013), 362 samples, 16S V4, 2x250 (3,651,784 read pairs); SILVA 138.2 DADA2 training set (to genus) and species set
* R: R version 4.6.1 (2026-06-24) / dada2 1.36.0
* Python: Python 3.13.15 / pydada2 0.1.0 (5e6453a)
* Machine: Intel(R) Core(TM) Ultra 7 265H, 16 logical CPUs, Linux
* Runs: 2 x R @ 8 thr, 2 x py @ 8 thr

### Taxonomy

Bootstrap confidences use different random numbers (deviation #2 in
docs/porting-notes.md), and R itself breaks ties with `std::random_device`, so R runs are
not exactly reproducible either (on tied genera). The criterion is therefore statistical.

| 420 non-chimeric ASVs | pydada2 vs R | R vs R |
|---|---|---|
| identical Kingdom | 420 | 420 |
| identical Phylum | 420 | 420 |
| identical Class | 420 | 420 |
| identical Order | 420 | 420 |
| identical Family | 420 | 420 |
| identical Genus | 412 | 420 |
| identical Species | 420 | 420 |
| identical at all levels | 412 | 420 |
| median \|Δ bootstrap\| | 0 | 0 |
| max \|Δ bootstrap\| | 23 | 1 |
| entries outside 3 sigma binomial noise | 1 | 0 |
| disagreements with R bootstrap far from 50 | 0 | 0 |

The R bootstraps at the levels where pydada2 differs are 41 to 52, close to the `min_boot=50` cutoff: borderline calls.
